# Clock24

> 一天是一个圆，不是两圈。

一个把 24 小时摊平成一个完整圆环的时钟。没有 12 小时制的自我重复，时针一天只走一圈。

**[在线预览](https://xsp20040203.github.io/clock24/)**（开启 GitHub Pages 后生效）

## 为什么

普通钟表把一天切成两半，于是 7:00 和 19:00 长在同一根指针上。你还得靠 AM/PM 才能分辨自己是要去上班还是要睡觉。

Clock24 不给指针这个机会。0 时在正上方，顺时针转满一圈就是一天。太阳那一段弧和夜里的那一段，在同一张盘上分得清清楚楚。

## 特性

- **24 小时环** — 24 格刻度，每 3 小时一个长刻度并标注数字
- **连续走针** — 光点按真实秒数平滑滑行，不跳格
- **昼夜弧** — 0–5 时与 19–24 时的那两段轨道亮度更低，代表没有配给到光的时间
- **环境光** — 整页色温跟着小时变化，正午最暖，深夜几乎退回靛蓝
- **日进度** — 百分比 + 一条细轨，`0.00%` 精确到小数点后两位
- **午夜倒计时** — 今天还剩多少
- **年内进度** — 这一年过去了多少，按真实天数算闰年
- **深/浅两套皮肤** — 默认暗色（OLED 友好），选择会记住
- **键盘可用** — `空格` 暂停走针，`T` 换肤
- **无依赖** — 纯 HTML + CSS + 原生 JS，没有构建步骤，没有打包器

## 运行

直接双击 `index.html` 就能跑。

想用本地服务器：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 无障碍

- 表盘是 `role="img"` 并带 `<title>` / `<desc>`，读屏能听到它是什么
- 数字时间用 `<time>` 元素，`aria-live="off"`——秒级朗读会变成骚扰
- 所有按钮 ≥ 44×44px，焦点环可见
- 遵循 `prefers-reduced-motion`

## 浏览器

Chrome / Edge / Firefox / Safari 的现代版本。用到了 `aspect-ratio`、CSS 自定义属性与 `requestAnimationFrame`。
