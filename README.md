# Clock24

> 一天是一个圆，不是两圈。

一个把 24 小时摊平成一个完整圆环的时钟。没有 12 小时制的自我重复，时针一天只走一圈。

**当前版本：v2.0** · [更新日志](CHANGELOG.md)

在 URL 后面加 `?tz=Asia/Tokyo` 就能直接开在东京时间上。

## 为什么

普通钟表把一天切成两半，于是 7:00 和 19:00 长在同一根指针上。你还得靠 AM/PM 才能分辨自己是要去上班还是要睡觉。

Clock24 不给指针这个机会。0 时在正上方，顺时针转满一圈就是一天。太阳那一段弧和夜里的那一段，在同一张盘上分得清清楚楚。

## 特性

### 表盘

- **24 小时环** — 24 格刻度，每 3 小时一个长刻度并标注数字
- **连续走针** — 光点按真实秒数平滑滑行，不跳格
- **昼夜弧** — 0–5 时与 19–24 时的那两段轨道亮度更低，代表没有配给到光的时间
- **环境光** — 整页色温跟着小时变化，正午最暖，深夜几乎退回靛蓝
- **日出 / 日落** — 按经纬度算出的两个刻度钉在环上，附昼长
- **日进度** — 百分比 + 一条细轨，精确到小数点后两位
- **午夜倒计时** — 今天还剩多少
- **年内进度** — 这一年过去了多少，按真实天数算闰年

### v2.0 新增

- **任意时区做表盘** — 十座城市任选，夏令时按当天真实偏移算，不写死
- **多时区对照条** — 本地 / UTC / 纽约 / 东京 四格并排，跨日的会标出「明天 +1」
- **12 / 24 制切换** — 数字读数可切 12 小时并显示 AM/PM；**圆环永远是 24 小时**，这是它的意义所在
- **日出日落刻度** — NOAA 简化式，可用「定位」按当前位置更新，也能手填经纬度
- **秒表** — 开始 / 暂停 / 分段 / 清零，分段保留最近 30 条
- **深链** — `?tz=` `?lat=` `?lon=` `?h12=1`，方便收藏某个时区的视图

### 通用

- **深浅两套皮肤** — 默认暗色（OLED 友好）
- **偏好全部记住** — 主题、时区、制式、坐标都落在 localStorage
- **键盘可用** — `空格` 暂停，`T` 换肤，`F` 切制式；面板可方向键切换
- **零依赖** — 纯 HTML + CSS + 原生 JS，没有构建步骤，没有打包器

## 运行

直接双击 `index.html` 就能跑，不需要装任何东西。

想用本地服务器（定位 API 需要 `https` 或 `localhost`，双击打开的文件协议下用不了）：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 深链参数

| 参数 | 例子 | 作用 |
|---|---|---|
| `tz` | `?tz=America/New_York` | 表盘用哪个时区 |
| `lat` `lon` | `?lat=51.5074&lon=-0.1278` | 算日出日落用的坐标 |
| `h12` | `?h12=1` | 直接开成 12 小时制 |

```text
index.html?tz=Europe/London&lat=51.5074&lon=-0.1278
```

## 关于日出日落

用的是 NOAA 那套常用简化式：先算太阳赤纬和时差方程，再解时角。误差在几分钟量级——够用来在盘上钉一颗钉子，不够用来做天文观测。

极昼极夜会返回对应状态，不会算出乱七八糟的数字。

## 无障碍

- 表盘是 `role="img"` 并带 `<title>` / `<desc>`，读屏能听到它是什么
- 数字时间用 `<time>` 元素，`aria-live="off"`——秒级朗读会变成骚扰
- 面板是真 tablist：`role="tab"` / `aria-selected` / 方向键 / Home / End
- 所有按钮 ≥ 44×44px，焦点环可见
- 遵循 `prefers-reduced-motion`

## 浏览器

Chrome / Edge / Firefox / Safari 的现代版本。用到了 `Intl.DateTimeFormat` 的时区能力、`aspect-ratio`、CSS 自定义属性与 `requestAnimationFrame`。
